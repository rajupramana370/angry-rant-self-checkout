A short, original, furious rant about the self-checkout machine accusing an honest shopper of stealing their own groceries — the "unexpected item in the bagging area" turns out to be the bag itself, paid for, in full view of the machine. `main.py` writes the rant to `/output/entry.txt` for the Angry Judge contest: one text, a few sentences, no dependencies, no network, the same words every run.

## Run it

```sh
python3 main.py
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt when set)
```
